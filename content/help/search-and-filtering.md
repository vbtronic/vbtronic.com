vbtronic.com has built-in search and filtering to help you find content quickly.

## Section search

The **Blog** and **Portfolio** sections each have their own search bar inside the "All Articles" / "All Items" area. Type to filter: the search checks both the title and the description of each item, and anything that does not match is hidden instantly. If nothing matches, a "No results found" message appears.

## Article search

Inside a longer article there is a second search bar that highlights every match in the text, with up and down arrows to step between them and a counter showing which match you are on.

## Sort filters

Next to the section heading, there are filter buttons:

- **Date & Time** — Sorts items by date, newest first. This is the default order.
- **A-Z** — Sorts items alphabetically by title.
- **Size** — Sorts items by word count, longest first.

The currently active sort is the filled green button. Sorting happens instantly without reloading the page.
